# 📊 质量可视化平台

基于 Streamlit 构建的智能化质量数据可视化平台，帮助质量经理全面掌握质量状况。

## 🔗 在线访问

**Streamlit Cloud**: [点击访问](https://your-app-name.streamlit.app)

## ✨ 功能特性

### 四大核心板块

1. **质量工作** - 年度目标、客户质量、漏测DI、事故率
2. **质量改进** - TOP问题、事故复盘、举一反三
3. **版本质量** - TAPD实时缺陷统计、版本风险看板
4. **QA事项** - QA检查、问题闭环、工作计划

### AI智能分析

- AI健康度评估
- 智能预警中心
- 趋势预测

## 🚀 快速开始

### 本地运行

```bash
pip install -r requirements.txt
streamlit run main.py
```

### Docker 部署

```bash
docker-compose up -d
```
